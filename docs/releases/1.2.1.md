Pocketwerk 1.2.1 is a security update. Please install it.

## Security

- **`pocketwerk://` links from other apps now ask first.** Until now, any website, mail or document could use a `pocketwerk://` link to add items to your groups, open or quit a group's apps, or change your Dock profiles, without asking. Pocketwerk now checks which app opened the link. Links from a browser, Mail or any other app ask before they change anything. Links from Shortcuts, the `pocketwerk` command line tool and Pocketwerk's own Dock icons still run without asking.
- A `pocketwerk://` link with a repeated parameter no longer crashes Pocketwerk.

If you run `open "pocketwerk://..."` in Terminal, Pocketwerk now asks too. Use the `pocketwerk` command line tool instead.

The full list is in the [changelog](https://github.com/DigitalIQ/pocketwerk/blob/main/CHANGELOG.md).

## Upgrading

Install the new version over the old one (download the DMG, or run `brew upgrade --cask pocketwerk`). Your groups, Dock icons and profiles stay.

## Install

Requires macOS 26 Tahoe or later, Apple Silicon or Intel.

- Download `Pocketwerk-1.2.1.dmg` below, open it and drag Pocketwerk into Applications.
- Or use Homebrew: `brew install --cask digitaliq/tap/pocketwerk`

## First launch

Pocketwerk is not notarized by Apple, so macOS blocks the first launch of a new download once.

1. Open Pocketwerk and click **Done** in the warning.
2. Open **System Settings > Privacy & Security**.
3. Scroll down to **Security** and click **Open Anyway** next to Pocketwerk.
4. Click **Open Anyway** again and confirm with your password or Touch ID.
