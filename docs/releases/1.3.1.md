Trackpad swipes now move the popup as soon as a horizontal gesture is recognized. A shorter swipe switches groups, and Pocketwerk calculates page counts as needed during navigation.

Pocketwerk also uses less memory in the background. It loads popup icons on demand, reuses rendered images, limits its image caches by memory cost and releases the management window when you close it.

Download `Pocketwerk-1.3.1.dmg` for Apple Silicon or Intel, or update with `brew upgrade --cask pocketwerk`.
